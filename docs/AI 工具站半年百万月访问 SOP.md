# 阶段 0：选词与验证（第 1 周）

## 步骤 0\.1：选定细分动作

**动作：**从以下 5 个图片细分动作中选择 1 个作为核心赛道：

|动作|已验证成功案例|竞争评估|
|---|---|---|
|upscaler（放大）|aiupscaler\.ai（早期）、ezenhancer\.ai 含此功能|中（小站多，易占位但点击少）|
|enhancer（增强）|ezenhancer\.ai（132 万/月）、enhancephoto\.ai|中低|
|remover（移除）|removerai\.io（20 万/月，3 个月翻 9 倍）|低（长尾组合极多）|
|colorizer（上色）|ezenhancer\.ai / enhancephoto\.ai 均含此功能|低|
|editor（编辑）|photoeditorai\.io（227 万/月）、ezcreate\.ai（148 万/月）|中高（但新站已验证可进）|

**判据：**选定后写入项目文档，后续所有页面围绕该动作展开。

**证据：**9 个成功新站中 7 个为图片类，图片赛道对新站无护城河；视频大词仅 ai music video generator 一个细分有新站进入。

## 步骤 0\.2：生成「动词\+对象」组合词库

**动作：**以选定动作为核心，横切 15\-25 个对象，每个组合生成一个独立关键词。

**模板：**

```text
[动作] + [对象] = 独立页面关键词

示例（remover 赛道）：
background remover → ai background remover
video background remover
logo background remover
watermark remover
object remover
gif background remover
png transparent background maker
webp background remover
bulk background remover
green screen remover
person remover from photo
blur remover
background changer
white background maker
signature background remover
```

**判据：**词库 ≥ 20 个组合词，每个词对应一个未来的独立工具页。

**证据：**removerai\.io 用此方法切出 16 个工具页，两周一页稳定上新，3 个月流量翻 9 倍至 20 万/月。

## 步骤 0\.3：验证搜索量与竞争度

**动作：**对词库中每个词执行以下验证：

1. 用 Google Trends 确认该词有持续搜索行为（非零搜索）

2. 用 Google Keyword Planner 或 SimilarWeb 获取月搜索量估算

3. 手动搜索该词，检查第一页：是否有巨头（Adobe/Canva）垄断？是否有新站（域名年龄 \< 1 年）出现？

4. 标记每个词的竞争等级：低（第一页有 ≥2 个新站）、中（1 个新站）、高（全无新站）

**判据：**词库中 ≥ 60% 的词竞争等级为「低」或「中」。若高竞争词超过 40%，回到步骤 0\.2 补充更多长尾对象。

**输出：**一份关键词清单表格，包含：关键词、月搜索量估算、竞争等级、对应对象、计划上线月份。

**高级玩法（可选）：**哥飞信息增量方法论——自己创造新词。参考 higgsfield 造出 Earth Zoom Out 玩法，全网最早页面稳拿第一。初级是跟进别人上过的页，中级是预测会火的词提前占坑，高级是自己造玩法让全球用户来搜。

# 阶段 1：建站与首批页面（第 2\-4 周）

## 步骤 1\.1：域名与基础设施

**动作：**

1. 注册新域名（优先 \.ai / \.io / \.com，与产品名一致）

2. 配置服务器（推荐 Vercel / Netlify 等 Serverless 平台，或云服务器）

3. 接入 AI 模型 API（图片处理类推荐 Stable Diffusion / Real\-ESRGAN 等开源模型，或调用第三方 API）

4. 配置 Google Search Console，提交 sitemap

5. 配置 Google Analytics 4

**判据：**域名可正常访问，Search Console 显示「已验证」，sitemap 可通过 /sitemap\.xml 访问。

**警告：**禁止使用老域名。哥飞 2026\-06 复盘：$17K 买 400 条外链救不回老站，同样的词换新域名上站效果是十倍。

## 步骤 1\.2：开发首批工具页（5\-10 个）

**动作：**从词库中选竞争度最低的 5\-10 个词，逐个开发独立工具页。

**每页必须满足：**

- **真能用：**免费、免登录、即开即用、结果秒出（≤ 5 秒出结果）

- **一页一词：**URL slug、title、h1、正文核心词统一为该页目标关键词

- **单页约 800 词：**包含功能说明、使用步骤、FAQ、对比内容

- **图文演示：**至少 1 张 before\-after 对比图或操作截图

- **结构化数据：**添加 SoftwareApplication / HowTo / FAQ 结构化数据

- **比竞品更优：**免费额度更高、无水印、速度更快，至少一项优于第一页竞品

**判据：**5\-10 个工具页全部上线，每页通过 PageSpeed Insights 移动端评分 ≥ 80。

**证据：**哥飞社群经验：「现在光靠文章获取 SEO 流量已经比较难了，做精品工具页、强交互页面，能真正满足用户需求，所以能拿到排名。」谷歌靠用户行为数据（点开、停留、使用、回头）判定工具页质量。

## 步骤 1\.3：搭建模型名占坑页（3\-5 个）

**动作：**调研当前热门 AI 模型（如 Nano Banana、Sora 2、Veo 3、Kling 等），为每个模型建一个专页。

**页面模板：**

```text
URL: /models/[模型名]
Title: [模型名] - 免费在线使用 | [你的品牌]
H1: 在线使用 [模型名]
内容:
- 模型介绍（来源、能力、发布时间）
- 如何使用（你的工具如何调用/模拟该模型能力）
- 效果展示（before-after 示例）
- 与同类模型对比
- FAQ
```

**判据：**3\-5 个模型名页上线，且每个页面对应的模型在 Google Trends 有搜索量。

**证据：**creen\.ai 建了 12 个模型名页（sora\-2 / veo / kling\-ai / wan\-ai / nano\-banana 等），吃模型名搜索量且无巨头竞争。Nano Banana 等模型每次发布自带巨量搜索，全网没人做专页，1 小时上线就是第一。

## 步骤 1\.4：sitemap 与技术 SEO

**动作：**

1. 生成 sitemap\.xml，包含所有工具页和模型页

2. 配置 robots\.txt，允许全量爬取

3. 添加 hreflang 标签（为后续多语言做准备）

4. 在 Search Console 提交 sitemap

5. 申请 Adsense（上线当天提交，哥飞实测老站带新站 5 天过审）

**判据：**Search Console 中 sitemap 状态为「成功」，已发现页面数 = 实际页面数。Adsense 审核中或已通过。

# 阶段 2：扩页与分发测试（第 2\-3 月）

## 步骤 2\.1：按节奏扩页（两周一页）

**动作：**从词库中按优先级每两周上线 1 个新工具页，第 3 个月末累计达到 20\+ 工具页。

**每页上线检查清单：**

* [ ] URL slug 与目标关键词一致

* [ ] Title 包含目标关键词，≤ 60 字符

* [ ] Meta description 包含目标关键词，≤ 160 字符

* [ ] H1 为目标关键词或其变体

* [ ] 正文约 800 词，关键词自然出现 3\-5 次

* [ ] 工具功能可用，出结果时间 ≤ 5 秒

* [ ] 至少 1 张 before\-after 对比图

* [ ] FAQ 模块 ≥ 3 条，含 FAQ 结构化数据

* [ ] 已加入 sitemap\.xml

* [ ] 已在 Search Console 请求索引

**判据：**第 3 月末工具页 ≥ 20 个，sitemap lastmod 显示持续更新（每月 \+1\~2 页）。

**证据：**removerai\.io 的 lastmod 从 2026\-01 滚到 05 每月 \+1\~2 页，稳定上新让谷歌持续感知站点活跃，3 个月流量翻 9 倍。

## 步骤 2\.2：社媒账号养号与内容测试

**动作：**

1. 注册并完善 TikTok / YouTube Shorts / Instagram Reels 账号，品牌名与网站一致

2. 每周发布 3\-5 条 before\-after 效果对比短视频（15\-30 秒）

3. 视频结构：3 秒展示「差的原图」→ 工具操作过程 → 惊艳结果 → 评论区引导「搜索 \[品牌名\]」

4. 每条视频带相关 hashtags（\#aiimage \#photoenhancer \#beforeafter 等）

5. 记录每条视频的播放量、点赞、评论、引流效果

**判据：**第 3 月末发布 ≥ 30 条视频，找到至少 1 个播放量破 10 万的视频方向（爆款模板）。

**证据：**图片工具的天然分发场是 TikTok / Reels / YouTube Shorts——before\-after 效果对比是这个品类最不需要语言的病毒内容。creen\.ai DR 仅 17 却 223 万月访问，靠的就是社媒分发驱动。

**Reddit 打法（可选）：**先养号，再自建产品 subreddit 当 landing page（留 r/你的产品名 不会被删，点击自动跳转）。目标市场选渠道：英语区是 YouTube/X/Reddit/TikTok，俄语区是 Telegram。

## 步骤 2\.3：数据复盘与方向确认

**动作：**第 3 月末执行一次完整复盘：

1. 从 Analytics 导出各页面流量，找出 TOP 5 流量页

2. 从 Search Console 导出各页面排名关键词和点击量

3. 从社媒后台导出各视频播放量和引流数据

4. 确认：哪个页面/哪个视频方向起势？

**判据：**月访问量达到 1\-10 万。明确 1\-2 个起量方向，写入阶段 3 押注计划。

**异常处理：**若第 3 月末月访问 \< 5000，检查：\(1\) 工具页是否真能用？\(2\) 社媒视频是否有播放量？\(3\) 选词是否竞争过高？若工具页无排名且社媒无播放，回到阶段 0 重新选词。

# 阶段 3：放量与冲量（第 4\-5 月）

## 步骤 3\.1：押注病毒功能页

**动作：**基于阶段 2 的社媒数据，开发 3\-5 个病毒功能页，每个对应一个 TikTok/Reels 爆款玩法。

**病毒功能页参考（来自 creen\.ai 的 27 个 features 页）：**

|功能页类型|示例|
|---|---|
|身份变换|gender\-swap、age\-progress、baby\-predictor|
|风格迁移|studio\-ghibli\-filter、pixar\-style、anime\-filter|
|趣味工具|ai\-palm\-reading（AI 看手相）、passport\-photo\-maker、photo\-to\-caricature|
|视频生成|ai\-dance\-video、lip\-sync、ai\-talking\-photo、ai\-youtube\-shorts\-generator|
|外貌编辑|ai\-hairstyle\-change、outfit\-swap、character\-swap|

**判据：**3\-5 个病毒功能页上线，每个页面配套 ≥ 5 条社媒视频。

**证据：**creen\.ai 的 27 个 /features/xxx 页是其 223 万流量的重要来源——这类词平时搜索量不大，但被 TikTok/Reels 病毒式带起时，能抢在巨头反应前截住流量。

## 步骤 3\.2：新模型热点抢坑

**动作：**

1. 关注 2026 年下半年 AI 模型发布日历（OpenAI / Google / Anthropic / 国内大厂）

2. 新模型发布后 24 小时内上线对应 /models/\[模型名\] 页面

3. 同步发布 2\-3 条该模型的效果演示视频

4. 在页面中引导用户使用你的工具体验该模型能力

**判据：**阶段 3 内至少押中 1\-2 个新模型热点，对应页面在 Search Console 出现展示量。

**证据：**Nano Banana 模型发布时自带巨量搜索，全网无人做专页，creen\.ai 第一时间上线 /models/nano\-banana 页，稳稳吃第一波流量。

## 步骤 3\.3：非英语市场扩展

**动作：**从英文站已验证有流量的页面中，选 TOP 5 页面，翻译并优化为 1\-2 个非英语版本。

**优先级语言（按已验证效果排序）：**

1. 俄语（ezenhancer\.ai 俄语词「улучшить качество фото」14\.7 万月搜已实证进量）

2. 西班牙语

3. 葡萄牙语（巴西市场）

4. 日语

5. 德语 / 法语

**关键规则：**每个语言市场单独选词、单独优化，禁止批量机翻几十种语言（谷歌会判为重复站）。先翻译 1 个语言市场验证有效，再扩展下一个。

**判据：**1\-2 个非英语版本上线，对应语言 Search Console 出现展示和点击。

**证据：**ezcreate\.ai 铺 18 语言、creen\.ai 铺 36 语言吃到了量，但那是逐语言调过的结果，不是无脑机翻。

## 步骤 3\.4：放量分发

**动作：**

1. 将阶段 2 找到的爆款视频模板批量复制，每周发布 5\-7 条

2. 考虑投放少量测试预算（TikTok Ads / YouTube Ads）放大已验证的爆款视频

3. 拓展分发渠道：Reddit 相关 subreddit、Facebook 群组、Discord 社区、Telegram 频道（俄语区）

4. 与同类小工具站互换友链或合作推广

**判据：**第 5 个月月访问量达到 50\-100 万。直接流量 \+ 社媒流量占比 ≥ 50%（说明分发驱动有效）。

# 阶段 4：变现与放大（第 6 月）

## 步骤 4\.1：起量页面系列化

**动作：**将阶段 3 中起量的页面（病毒功能页或模型名页）扩展为系列页面。

- 若 gender\-swap 起量 → 扩展 age\-progress、baby\-predictor、face\-app 等身份变换系列

- 若某模型名页起量 → 扩展该模型的使用教程、对比、API 接入等相关页面

- 每个系列页保持「一页一词」原则

**判据：**起量方向扩展出 ≥ 5 个系列页面，系列总流量占全站 ≥ 30%。

## 步骤 4\.2：品牌词搜索量养成

**动作：**

1. 所有社媒视频结尾统一引导「搜索 \[品牌名\] 获取工具」

2. 在工具页 footer 和 about 页强化品牌名曝光

3. 发布品牌相关内容（博客、教程），承接品牌词搜索

4. 监控 Search Console 中品牌词的搜索量趋势

**判据：**品牌词月搜索量 ≥ 1 万，品牌词带来的流量占比 ≥ 15%。

**证据：**ezmaker\.ai 建站第 3 个月 25\.6 万访问，主力词是 ezmaker 品牌词——说明靠社媒/外部分发导流，用户记住品牌名后去搜索，SEO 负责接住这波流量。

## 步骤 4\.3：变现优化

**动作：**

1. 确认 Adsense 已通过审核并投放广告

2. 评估订阅制变现：免费额度 \+ 付费高级功能（高清导出、批量处理、无水印）

3. A/B 测试广告位置和订阅弹窗，优化 RPM 和转化率

4. 计算单用户价值（LTV）和获客成本（CAC），确认正循环

**判据：**Adsense 或订阅收入已产生，月收入 ≥ $1000（100 万访问量的保守估算）。

## 步骤 4\.4：站群评估（可选）

**动作：**若主站已跑通模式（月访问 ≥ 50 万且有正收益），评估是否启动站群：

1. 用同一套产品内核，注册新品牌域名

2. 选择不同细分动作（如主站做 enhancer，新站做 remover）

3. 新站与主站互相写对比文导权重（如「ezmaker vs ezcreate」）

4. 使用 WordPress multisite 批量管理（参考 ezmaker\.ai 的 /sites/25/ 路径）

**判据：**主站模式已验证盈利，且有足够资源维护第二个站。禁止主站未跑通就铺站群。

**证据：**photoeditorai / ezmaker / ezcreate 已被证实是同一团队的产品矩阵——photoeditorai 内嵌另两个子品牌页，ezmaker 写 vs ezcreate 对比文互导权重，一套内核、多品牌外壳、内部互链。

# 异常处理与停止条件

## 常见异常与处理

|异常|可能原因|处理动作|
|---|---|---|
|工具页上线 1 个月无排名|选词竞争过高 / 页面质量不足 / 未被收录|检查 Search Console 索引状态；优化页面内容和工具体验；换长尾词|
