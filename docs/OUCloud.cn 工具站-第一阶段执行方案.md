# oucloud.cn 工具站 · 第一阶段执行方案

## 0. 总体思路回顾

- 定位：工具箱矩阵站，靠长尾冷门工具聚合流量，不正面刚 PDF/图片压缩类红海关键词
- 技术路线：纯前端实现，静态托管（Cloudflare Pages / Vercel），零后端成本
- 第一阶段目标：4 周内上线 4 个"AI 替代不了"的工具，验证流量和排名情况，再决定是否扩量

---

## 1. 第一批做什么、按什么顺序

按"防御力（AI/手机工具替代不了的程度）+ 开发成本"排序，分两周两批上：

| 顺序 | 工具 | 为什么排在这 | 预计开发时间 |
|---|---|---|---|
| 1 | 颜色拾取器 | 纯前端最简单，先把项目框架和部署流程跑通 | 1 天 |
| 2 | 金额大写转换 | 规则型工具，防御力最强，实现难度低，是本批"确定性"代表 | 0.5 天 |
| 3 | Favicon 生成器 | 需要用到 Canvas 处理图片多尺寸导出，比前两个稍复杂，趁热乎做 | 1.5 天 |
| 4 | CSS 渐变生成器 | 交互最复杂（实时预览+代码生成），放最后做，前面攒的组件可以复用 | 2 天 |

**理由**：先做最简单的把整个"路由+首页导航+部署+SEO 基础设施"这套壳子搭起来，后面每加一个工具只是往壳子里塞内容，边际成本递减。如果反过来先啃最难的渐变生成器，框架没搭好，容易返工。

## 2. 技术方案

### 2.1 技术栈

- **框架**：React + Vite（轻量、构建快，你熟悉 PHP 的话上手 React 基础语法成本不高，且生态成熟、AI 辅助编码资料最多）
- **路由**：React Router，单页应用（SPA），但需要处理 SEO（见 2.3）
- **样式**：Tailwind CSS（开发速度快，配合 frontend-design 规范做视觉）
- **部署**：Cloudflare Pages（免费额度够用，且国内访问速度优于 Vercel，配合你的备案域名走国内解析更划算）

### 2.2 项目结构

```
oucloud/
├── src/
│   ├── components/
│   │   ├── layout/           # 顶部导航、底部、工具卡片等公共组件
│   │   └── tools/
│   │       ├── ColorPicker/
│   │       ├── RmbUppercase/
│   │       ├── FaviconGenerator/
│   │       └── CssGradient/
│   ├── pages/
│   │   ├── Home.jsx           # 工具导航首页
│   │   └── ToolPage.jsx       # 通用工具页壳（标题+工具区+说明文章区+相关推荐）
│   ├── data/
│   │   └── tools.json         # 工具元数据：slug、标题、描述、分类、关键词
│   └── router.jsx
├── public/
└── index.html
```

`tools.json` 是关键设计：新增工具时只需要写一个组件 + 在这个 json 里加一条元数据，首页导航、相关推荐、sitemap 都自动生成，不用每次手动改多处。

### 2.3 SPA 的 SEO 处理（重要，容易被忽略）

纯客户端 SPA 对百度收录不友好，建议：

- 用 **Vite 的预渲染插件**（如 `vite-plugin-prerender` 或 `vite-ssg`）在构建时把每个工具页生成静态 HTML，保留 SPA 的开发体验，同时首屏是纯 HTML，爬虫能直接抓到内容
- 每个工具页单独设置 `<title>` 和 `<meta description>`（写进 tools.json，构建时注入）
- 生成 `sitemap.xml`，构建脚本里自动扫描 tools.json 生成，提交百度站长平台

## 3. 每个工具的实现要点

### 3.1 颜色拾取器
- 核心：色板点选 + HEX/RGB/HSL 输入框实时互转，一键复制
- 加分项：常用色卡预设（Tailwind 色板、Material 色板），提高长尾词覆盖（"Tailwind 颜色对照表"这类词也能搜进来）

### 3.2 金额大写转换
- 核心：输入阿拉伯数字，输出中文大写金额，规则要覆盖到角分、整/正、负数、超大数字（万亿级）边界情况
- 这是纯规则算法，务必写单元测试覆盖边界值，因为财务场景用户零容错

### 3.3 Favicon 生成器
- 核心：上传一张图，自动裁剪并导出 16x16 / 32x32 / 180x180（apple-touch-icon）/ 192x192（安卓）等多尺寸，打包成 zip 下载，同时生成可直接复制的 `<link>` 标签代码
- 用 Canvas API 做缩放裁剪，全部本地处理不用上传服务器

### 3.4 CSS 渐变生成器
- 核心：拖拽控制点调整渐变角度/位置，多色标（可增删色标），实时预览，右侧实时生成 CSS 代码可复制
- 加分项：预设一批"高颜值渐变"模板供一键套用，这类模板本身容易被分享传播，带来外链和二次访问

## 4. 内容与 SEO 配置

每个工具页固定结构：

1. 工具功能区（上半屏，用户进来第一眼就能用）
2. 使用说明（怎么操作，2-3 步）
3. 补充知识块 300-500 字（例如金额大写页讲清楚"零""整"的书写规范，渐变生成器页讲 `linear-gradient` 语法基础）—— 这部分是长尾词覆盖的核心
4. 常见问题 FAQ（3-5 条，可配 FAQ 结构化数据，利于搜索展现）
5. "相关工具"推荐模块（从 tools.json 按分类自动拉取）

站点级配置：
- 提交百度站长平台 + 神马站长平台（移动端流量不能忽视）
- 生成并提交 sitemap.xml
- 首页做好工具分类导航（开发者工具 / 生活实用 / 设计辅助）
